## 2. 使うピンと所在

データは **底面 8 ピンヘッダの G26** を使用(`main.cpp` の `DATA_PIN=26`)。
電源(5V/GND)は底面ヘッダ、または Grove ポートから取れる(GND は本体内で共通なので混在可)。
**ピン位置は本体底面のシルク表示で必ず確認**すること。

| 信号 | 使うピン | 所在 |
|------|---------|------|
| WS2812B DATA | **G26** | 底面 8 ピンヘッダ(G0/G26/G36 + 電源) |
| 5V | 5V | 底面ヘッダ or Grove。USB給電時に出力 |
| GND | GND | 底面ヘッダ or Grove(共通) |
| (代替データ) | G32 / G33 | Grove ポート(HY2.0-4P = 5V/GND/G32/G33)。使う場合は `DATA_PIN` を変更 |

> Grove ケーブルの線色は製品によりバラバラ。必ずテスターで 5V/GND を確認すること。
> G36 は入力専用・G0 は起動ストラップのためデータには使わない([design.md](design.md) 参照)。

## 3. 基本配線(USB 給電・最小構成)

```
M5StickC (底面ヘッダ)          WS2812B (先頭)
  G26 ──[330Ω]───────────────▶ DIN
  GND ───────────┬────────────  GND      ★必ず共通
  5V  ───────────┼────────────  5V (VDD)
                 │
              [1000µF]  ← 5V–GND 間、先頭LEDの直近に。極性注意(長足=+)
```

- **330Ω** は先頭 LED の DIN 直近に置く(反射・リンギング抑制)。
- **1000µF** は先頭 LED の電源端直近。全点灯時の突入電流を吸収。
- データ線(G26→DIN)は**できるだけ短く**。

## 4. 外部5V電源を使う構成(フル輝度・推奨)

```
外部5V(+) ───────────────────  5V (VDD)
外部5V(GND)──────┬────────────  GND
M5StickC GND ────┘   ★外部電源とGNDを共通に(データの基準電位を揃える)
M5StickC G26 ─[330Ω]─────────▶ DIN
   ※このとき M5StickC 側の 5V はストリップに繋がない(電源は外部に一本化)
```

- M5StickC は USB から、ストリップは外部5Vから給電。**GND は必ず1点で共通**。
- 共通 GND を忘れるとデータ基準がずれて点灯しない/暴走する(最頻トラブル)。

## 5. レベルシフト(3.3V データの確実化)

WS2812B DIN の High しきい値 ≈ **0.7×VDD = 3.5V**(VDD=5V時)。ESP32 出力 3.3V は
わずかに下回る。短距離・20個なら直結で動くことが多いが**非保証**。下記いずれかで確実化。

### 5.1 ロジックレベルシフタ 74AHCT125(最も確実)

74AHCT は VCC=5V で VIH(min)≈2.0V のため 3.3V 入力を確実に High と認識し、出力は 5V 振幅。

```
74AHCT125 (1ch 使用)
  VCC (14) ── 5V
  GND (7)  ── GND
  1OE (1)  ── GND        (出力イネーブル, active-low → 常時有効)
  1A  (2)  ── M5StickC G26 (3.3V データ入力)
  1Y  (3)  ──[330Ω]──▶ WS2812B DIN (5V データ出力)
```

### 5.2 ダイオード降圧(簡易・部品1個)

ストリップの **+5V 線に 1N4007 を直列**に入れ VDD を下げる:

| 直列ダイオード | VDD 概算 | しきい値 0.7×VDD | 3.3V で High? |
|:---:|:---:|:---:|:---:|
| 1本 | ≈ 4.3V | ≈ 3.0V | ◎ |
| 2本 | ≈ 3.7V | ≈ 2.6V | ◎(LEDやや暗) |

- 注意: ダイオードは電流ぶん発熱(Vf×I、例 0.8V×0.8A≈0.6W)。**電流に見合う定格**(1N4007=1A)を選び、高電流では発熱確認。
- VDD が下がるぶん最大輝度・電流もわずかに低下する(安全側)。

### 5.3 まずは直結で試す
20個・短距離なら直結で動く例が多い。**先頭LEDの色化け/ちらつき**が出たら 5.1 か 5.2 を追加する、という順で良い。

## 6. 組立手順

1. M5StickC の 5V/GND(底面ヘッダ or Grove)をテスターで確認(USB 接続時 ~5V)。
2. 330Ω を先頭 DIN に、1000µF を先頭 5V–GND に取り付け。
3. GND を共通化(外部電源時は外部 GND も)。
4. G26 →(330Ω)→ DIN を接続。データ線は短く。
5. (任意)レベルシフト 5.1/5.2 を挿入。
6. `pio run -t upload` 後、Button A で点灯確認。

## 7. トラブルシュート

| 症状 | 原因の候補 | 対処 |
|------|-----------|------|
| 全く光らない | GND 未共通 / DIN-DOUT 逆 / データピン違い | GND 共通確認、矢印(→)方向に DIN へ、G26 を確認 |
| 先頭だけ色化け・ちらつき | 3.3V データのしきい値不足 | レベルシフト(§5)、データ線短縮、330Ω 追加 |
| 後半が暗い/赤っぽい | 電圧降下(電流不足・線が細い) | 電源強化(外部5V)、輝度↓、太い電源線、両端給電 |
| 点灯の瞬間にリセット/落ちる | 突入電流で電圧降下 | 1000µF 追加、電流上限↓(`p=`)、外部電源 |
| しばらくで M5StickC が熱い/落ちる | Grove 経由で過大電流 | 外部5V給電へ、`p=` で上限↓ |
| 色が想定と違う | 色順 (GRB/RGB) 違い | 本FWは GRB。違えば `addLeds<...>` の色順を変更 |

## 8. 安全メモ
- WS2812B は 5V。M5StickC の 3.3V ピンには繋がない。
- 電解コンデンサの極性に注意(逆挿しは破裂)。
- 大電流時は Grove コネクタ・配線の発熱を触って確認。常用は外部給電に。
