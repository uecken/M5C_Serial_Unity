# proto_m5stickc_ws2812b — 実測・検証プラン

「M5StickC の 5V で何個・どの輝度まで賄えるか」を**実機で確かめる**手順。
理論は [design.md](design.md) を参照(FastLED モデルは実機より楽観的なので実測が要る)。

## 1. 計測器の選択肢

| 方法 | 測る場所 | 長所 | 短所 |
|------|---------|------|------|
| **USB電流電圧計**(インライン) | 給電源 ↔ M5StickC の USB 間 | 挿すだけ。電圧降下も見える | M5StickC 自体の消費も含む |
| ベンチ電源(電流表示付) | 外部5V → ストリップ | ストリップ単体の電流が分かる | 機材が要る |
| テスター(電流レンジ) | ストリップ +5V 線に直列 | 安価 | 大電流レンジ/ヒューズ注意、挿し替え手間 |

最低でも **USB電流電圧計**1つあれば「足りるか」は判定できる。

## 2. 共通の準備

1. [wiring.md](wiring.md) どおり配線(まず §3 基本構成、給電は検証したい経路で)。
2. 書き込み: `pio run -t upload`、`pio device monitor` でシリアル監視。
3. シリアルに毎操作 `est=...mA(@full) cap=...mA -> eff_bri=...` が出る。これと計測値を突き合わせる。

## 3. 試験A — 輝度↔電流(20個・黄, 給電経路ごと)

`n=20`、`p=2000`(上限を実質無効化して素の電流を見る)で `b=` を振り、電流を記録。

シリアル操作例:
```
n=20
p=2000
y
on
b=255   (記録) → b=204 → b=128 → b=77 → b=26
```

記入表(給電経路ごとに1枚):給電 = ☐PC USB ☐5V2A充電器 ☐外部5V

| 輝度 b | 実機概算(design表) | 実測電流 [mA] | 5V実測 [V] | 安定? | 先頭色OK? |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 255 | ~814mA | | | | |
| 204 | ~654mA | | | | |
| 128 | ~414mA | | | | |
| 77  | ~254mA | | | | |
| 26  | ~94mA | | | | |

判定の目安:
- **電圧降下**: 5V が ~4.7V を下回る、または点灯時に急落 → その経路ではその条件は過負荷。
- **不安定/リセット/色化け** が出たら、その輝度は実用上限超え。

## 4. 試験B — 個数↔電流(フル輝度)

`b=255`、`p=2000`、`y` で `n=` を増やし、電圧降下/不安定が出る個数を探す。

```
b=255
p=2000
y
on
n=5 → n=10 → n=12 → n=15 → n=20  (各で電流・電圧・安定を記録)
```

| 個数 n | 実機概算 | 実測 [mA] | 5V [V] | 安定? |
|:---:|:---:|:---:|:---:|:---:|
| 5  | ~204mA | | | |
| 10 | ~407mA | | | |
| 12 | ~488mA | | | |
| 15 | ~611mA | | | |
| 20 | ~814mA | | | |

→ 「PC USB で安定して点く最大個数(フル輝度)」「5V2A 経路での上限」を確定する。

## 5. 試験C — FastLED 電流上限の実効性(モデル差の確認)

design.md §4.2 のとおり FastLED の上限は実機より甘い。実際にどれだけズレるか測る。

```
n=20
y
on
p=150 → p=300 → p=450  (各で実測電流とシリアルの eff_bri を記録)
```

| 設定 cap [mA] | シリアル eff_bri | 実測電流 [mA] | 実測/設定 比 |
|:---:|:---:|:---:|:---:|
| 150 | | | |
| 300 | | | |
| 450 | | | |

- 「実測/設定 比」が design.md の予想(~1.4倍)に近いか確認。
- 真に守りたい予算(例 500mA)があれば、比から逆算して安全な `p=` を決める
  (例: 比1.4なら 500/1.4 ≈ `p=350`)。決めた値を `main.cpp` の `MA_PRESETS`/既定に反映。

## 6. 試験D — 発熱・連続点灯

最終的な常用条件(個数・輝度・給電)で 5〜10分連続点灯し、触診で確認:

| 箇所 | 許容の目安 |
|------|-----------|
| Grove コネクタ/配線 | ほんのり温かい程度。熱い→電流過大、外部給電へ |
| M5StickC 本体 | 通常運用温度。異常発熱なら経路見直し |
| ダイオード(使用時) | 熱い場合は定格/本数を再検討 |

## 7. 合否基準(この実験のゴール)

- ☐ 狙いの条件(例: 20個・適正輝度)で **5V が 4.7V 以上を維持**し、リセット/色化けがない。
- ☐ その条件の **実測電流**が、選んだ給電経路の供給能力内(PC USB:≤500mA / 5V2A:≤~1A 目安)。
- ☐ 連続点灯で **異常発熱がない**。
- ☐ 上記を満たす `n` / `b` / `p` を確定し、README・`main.cpp` 既定に反映。
