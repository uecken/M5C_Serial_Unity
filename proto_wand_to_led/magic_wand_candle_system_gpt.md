# 魔法の杖・ろうそく演出システム — 提案資料

> 作成 2026-05-24 / ハリポタ風「光が移る」演出。**MCUなし(アナログ) vs MCUあり(XIAO系)** を比較し、
> 光センサ部品・価格・電池寿命・既製品の有無を調査して最適方式を提案する。
> （本書は検討メモ `proto_wand_to_led/` の正式資料。旧 GPT 素案を全面改訂）

---

## 1. 目的と演出フロー

ハリー・ポッター風の「**光が杖からろうそくへ移る**」演出を、店舗常設で実現する。

1. 店舗内の**隠し磁石**に杖先をタッチ → **杖先 LED が灯る**
2. 灯った杖をろうそくに近づける → **杖の光が消え**、**ろうそくが灯る**（＝光が移る）
3. ろうそくは**点灯を保持**。リセット（消灯）は自動消灯 or 別操作

### 確定した前提（ユーザー確認済み）
- **規模**: 店舗常設・複数台。受信側(ろうそく)はショーケース内 → **電池交換が難しい** → 長期駆動重視
- **優先軸**: 簡単・低コスト最優先（ただし MCU 方式も対等に評価）
- **信号方式**: **可視光（白色/電球色LED）で十分**（IR 変調受信は必須でない）
- **受信側電源**: **CR2032(220mAh)** または **LIR2032H(~60mAh, 充電式)**。**最低1週間(≥168h)** 駆動したい
- **杖**: 既製品の磁気スイッチ LED **「ADMGLW」**(btoshop, ¥660) が既に付いている

## 3. 杖側 ADMGLW と「光の移し替え」機構

### 杖 ADMGLW（btoshop, ¥660）仕様
- ウォームホワイト等 **9色**, **CR927(3V)**, 消費 **約10mA**, 磁石検出 **1〜3cm**, 11×11×5mm, リード20cm
- スイッチ挙動: 「磁石で ON/OFF 切替」=**トグル/ラッチ式とみて設計**（同型ゆらぎ版 MMGLFL が「ラッチ式」と明記）。
  ⚠ **実機で要確認**: もし**モーメンタリ**（磁石が近い間だけ点灯）だと「灯った杖を運ぶ」が成立しない → 杖にラッチ追加 or 演出見直し

### 「光の移し替え」＝杖OFF と ろうそくON を連動（追加電子回路なし／受動磁石で実現）
1. ろうそくの**フォトセンサ**（手前/上部・検出 ~3-5cm）が杖の光を捉え **ろうそくをラッチON**
2. ろうそくに**永久磁石を内蔵**（奥・近接 ~1-2cm）→ 杖 ADMGLW の磁気スイッチを**トグルOFF**
3. **センサを手前・磁石を奥に空間配置** → 「**先にろうそく点灯 → 次に杖消灯**」の順序ができ、光が移ったように見える

⚠ **干渉注意**: ろうそく内蔵の常設磁石は、ろうそく自身のリセット用リードSWを誤作動させる。
→ **ろうそくのリセットは磁石リードに頼らず、自動消灯タイマ（MCU）等にする**（MCU方式が有利な理由のひとつ）。

## 4. 既製品調査：「光トリガ自己保持LED」完成品は事実上存在しない

ユーザー依頼で調査（2026-05-24, web）。結論として**自作が妥当**。

- **光が当たると点灯し保持する完成品 LED/モジュールは見つからない。**
  - 出回る「**光控スイッチモジュール**(CdS+LM393, DO/AO出力)」は ①**保持しない**（光に追従するだけ）
    ②既定が「**暗い→ON**」の街灯ロジック（逆動作）③LED保持には別途ラッチ/MCU 必要 → 結局**自作**。
- **最も近い完成品（ただし磁気 or IR トリガ）**:
  - **btoshop MMGLFL「磁気スイッチ付ゆらぎLED」¥660**（**ラッチ式**, ウォームホワイト/オレンジ, CR927, ~10mA）
    ＝ろうそく側の完成品候補だが**磁気トリガ**。杖 ADMGLW と同型ファミリ。
  - **フローティングキャンドル＋魔法の杖セット（Homemory 等, 12本, 単4）**＝杖は**IRリモコン**式。
    「列に沿って順に点灯」可だが、**杖の可視光検出ではない**＆ボタン操作。
  - **脱出ゲーム用キャンドルプロップ**（escaperoomsupplier / YOPOOD / Halloween FX）＝**磁石 or 吹き消し**トリガ。
    「魔法の杖(磁石)で再点灯」を謳う製品あり ＝ **磁気式は実績豊富で最も簡単**。
- **含意**: 光検出方式は完成品が無く**自作**、磁気方式は完成品・実績が豊富。本提案は**光学式を本命**に自作する。

## 5. 実測知見：「フォトTR と LED を直列」では検出距離が極端に短い(~5mm)

> ユーザー実測(2026-05-24): TEPT4400 に LED を**直列**接続 → 杖を **~5mm 以内**に近づけないと点かない。

**原因＝直列接続（増幅・しきい値・ラッチが無い）**:
1. **増幅なし**: 直列だと「LED電流 = フォトTRの光電流」。フォトTRの光電流は普通の照度で数十µA〜。
   LEDの可視点灯には ~mA 必要 → **強い光＝至近距離**でしか足りない
2. **逆二乗則**: 点光源の照度は距離²で減衰（5mm→30mm で ~1/36）→ 一気に暗くなる
3. **電圧不足（3V電源）**: 白色LEDの Vf≈3V で、フォトTRの VCE 余裕が残らない

**対策（本提案 T1〜T3 が必要な理由）**: フォトTR に**負荷抵抗 R_L(10k〜1MΩ)で電流→電圧変換** →
**NPN/コンパレータ/MCUのADC で増幅・しきい値判定** → LED は**MOSFET/MCUでフル点灯＋ラッチ保持**。
これで検出距離は数cmに伸び、明るさは光量非依存。**＝「フォトTRでLEDを直接駆動しない」が鉄則。**
（切り分け確認: まず赤/橙LED(Vf低)に替える or 電源を上げると、電圧不足か増幅不足かを判別できる）

## 7. ★最速完成プラン → 実装済み（手元の XIAO nRF52840, `proto_mag-let-wand_to_candle/`）

**考え方**: §5 の通り直列LEDは増幅/しきい値/ラッチが無くて失敗。XIAO nRF52840 ならそれらを全部 MCU 側で実現でき、
アナログのコンパレータ/D-FF/MOSFETラッチが不要。**手元の XIAO ＋ フォトTR ＋ LED ＋ 抵抗**だけで動く。**実装済み**。

### 配線（実装の最終ピン配置）
```
[センサ/wake] 3V3 ──[470kΩ プルアップ(外付)]── D2(P0.28) ──[フォトTR C] / [フォトTR E]── GND
              暗=High / 光でフォトTR導通 → D2=LOW → 「LOW」で検出 & System OFF から wake(SENSE_LOW)
              検出距離/外乱光は 470k 値で調整(小さく=鈍く)。要ならアンプ内蔵フォトIC S9648(IRカット)/S7183 へ

[LED]   D0(P0.02) ┐
        D1(P0.03) ┴─[各 直列R ~100〜220Ω]── 電球色LED ── GND
        点灯(=光/wake)時に D0・D1 を HIGH にして駆動(2ピンでソース能力UP)。起動時/sleep中は OFF。
        炎ゆらぎが要れば USE_FLICKER=1 で D0/D1 を PWM。

[電源]  XIAO の 3V3、または BAT パッドに LIR2032H（XIAO が充電も兼ねる）
```

### 動作（実装どおり）
1. **起動 / Deep sleep 中**: D0/D1 = **OFF**
2. フォトTR で **D2=LOW → System OFF から wake**（リセット復帰, `RESETREAS.OFF` で判定）
3. **D0/D1 を HIGH にして点灯** → **今は30秒**保持（本番は `AUTO_OFF_MS` を3分へ）
4. 30秒後 **D0/D1 OFF → D2 を SENSE_LOW で再武装 → System OFF**（待機 ~1.5µA）
5. **「移し替え」**: ろうそく内蔵磁石で杖 ADMGLW を OFF（ろうそくは光検出時に点灯済み, §3）

### 実装ステータス（2026-05-24）
- `proto_mag-let-wand_to_candle/`（PlatformIO, board `seeed-xiao-afruitnrf52-nrf52840`）
- 2 env: **`seeed_xiao_nrf52840`**(簡易=USBで D2/光をポーリング観測, System OFF しない) /
  **`seeed_xiao_nrf52840_lowpower`**(本番=D2 wake + System OFF)。**両env ビルド成功・XIAO へ書込み確認済**。
- 切替マクロ: `LOWPOWER_SYSTEMOFF`(0/1), `USE_FLICKER`(0=solid HIGH / 1=PWMゆらぎ), 点灯時間 `AUTO_OFF_MS`。
- ⚠ 470k 未配線だと D2 フローティングで wake 不定 → 配線後に lowpower を使用。簡易env なら USB で安全に観測可。
- **発展**: ①実機 wake 確認 → ②本番3分へ・しきい値調整 → ③**BLE で複数ろうそく連動/呪文連動** →
  ④基板化/省電力最適化。`led_xiao_nrf52840/` のコードを土台に流用可。

## 8. 回路説明（量産・無MCU版の参考）

### T2（無MCU・堅牢, ~¥500）
```
フォトTR(+R_L) ──→ コンパレータ LM393/MCP6541（基準電圧を環境光より上に・ヒステリシス付）
                 ──→ D-FF TC4013（CLK/SET で「光検出」をラッチ）
                 ──→ Pch MOSFET AO3401A ──→ 電球色ゆらぎLED ──→ GND
リセット: リードSW を D-FF の RESET へ（※ろうそく内蔵磁石を使う場合は干渉回避のため自動消灯側に寄せる）
```
- 待機 ~µA、**点灯中は LED 連続**（PWM調光なし）→ 1週間は「店時間だけ点灯＋夜off」運用が前提
- 「とにかく動かす保険」としては磁気完成品 **MMGLFL(¥660)** も可

### T3（本命・XIAO nRF52840）
- §7 の通り。前段センサに **S9648（IRカット・アンプ内蔵）** を使うと外乱光耐性が一段上がる
- LIR2032H を BAT に載せれば XIAO が充電も担う（週次充電運用に好適）

## 10. 検証方法（実装後）
- ブレッドボードで §7(XIAO) → 必要なら T2(無MCU) を実機検証:
  ①暗所で杖LED近接→点灯/保持、②室内灯ON下での誤点灯有無、③磁石でリセット、
  ④消費電流をテスタ/µA計測（待機・保持／PWM平均）、⑤想定電源での連続点灯持続時間を実測
- 適応しきい値が昼夜・照明ON/OFFの環境光変化に追従するか確認
- S9648/S7183 を入れた場合の検出距離・外乱光耐性の改善を比較
