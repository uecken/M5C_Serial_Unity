▸ 使い方
① 杖の操作 → 画面が反応
  • 杖を上に振る → 🔆 Lumos（光球が点灯・持続）
  • 杖を下に振る → 🌑 Nox（消灯）
  • 杖を前に突く → 🔥 Incendio（オレンジ flicker）
  • ※ Aguamenti は杖シリアルコマンド a で送信
② このページ側
  1. Android Chrome / PC Chrome・Edge で開く（iPhone 不可）
  2. 初回のみ chrome://flags/#enable-experimental-web-platform-features を有効化して再起動
  3. 上の「📡 スキャン開始」を押し、Bluetooth スキャンを許可
③ 上映 (魔法の効果だけ見せる)
  • 魔法画面（球体）をダブルタップで 拡大⇄通常 を切替（スキャンは継続）。PC は Esc でも戻れます
  • キーボード L=Lumos / N=Nox / I=Incendio / A=Aguamenti / W=Wingardium(浮遊) で手動発火（杖が無くても上映可）
④ スマホ自体を杖にする (BLE 不要・iPhone でも可)
  • 「📱 スマホで魔法」にチェック（iPhone はモーション権限の許可が出る → 許可）
  • スマホを少し静止させてから 上に素早く振る → Lumos / 下に振る → Nox（上下が不明瞭な振りは無反応）
  • 重力基準フリック検出なので持つ向きは自由。ダブルタップで全画面にして振ると映えます
  • 🪶 ウィンガーディアム・レヴィオーサ（キー W / 手動ボタン / 杖 BLE）→ 羽が出現。スマホを上に傾けると羽が上、下げると下へゆっくり浮遊。羽をタップで解除

BLE が使えない端末でも、「📱 スマホで魔法」や下の「手動テスト」ボタン・キーボードでエフェクトを出せます。

⚠ BLE 受信は Android Chrome / PC Chrome・Edge のみ。iPhone・iPad は Web Bluetooth 非対応（手動テストの見た目だけ動作）。
